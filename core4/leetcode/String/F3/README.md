# LeetCode Problem 151: Reverse Words in a String (Medium)

## 🧩 Problem Statement

Given an input string `s`, reverse the order of the words.

A **word** is defined as a sequence of non-space characters.

The words in `s` are separated by one or more spaces.

Return a string where:

- The words appear in reversed order.
- Words are separated by a single space.
- No leading or trailing spaces are included.

### Constraints

- `1 <= s.length <= 10^4`
- `s` contains English letters, digits, and spaces.
- The returned string should not contain extra spaces.
- Aim for:
  - **O(n) time complexity**
