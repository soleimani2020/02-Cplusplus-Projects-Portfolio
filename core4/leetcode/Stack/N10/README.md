# Online Stock Span

## Problem

Design an algorithm that collects daily price quotes for a stock and returns the **span** of the stock's price for the current day.

The span is the maximum number of consecutive days, starting from the current day and going backward, where the stock price was **less than or equal to** the current day's price.

### Example

```text
Input:
100
80
60
70
60
75
85

Output:
1
1
1
2
1
4
6
