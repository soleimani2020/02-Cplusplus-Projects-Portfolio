# LeetCode 88: Merge Sorted Array

**Difficulty:** Easy  
**Topic:** Two Pointers, Array, Sorting  

---

## Problem Statement

You are given two integer arrays `nums1` and `nums2`, sorted in non-decreasing order.

- `nums1` has a size of `m + n`, where:
  - The first `m` elements contain valid values.
  - The last `n` elements are initialized with `0` and serve as extra space.
- `nums2` contains `n` valid elements.

Merge `nums2` into `nums1` so that `nums1` becomes one sorted array.

The merge must be performed **in-place**.

---

## Example

### Input

```text
nums1 = [1,2,3,0,0,0]
m = 3

nums2 = [2,5,6]
n = 3
